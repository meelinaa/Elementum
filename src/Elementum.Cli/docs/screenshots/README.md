# CLI screenshots

Add your terminal screenshots here so they can be referenced from [../../README.md](../../README.md).

**Tips**

- Capture the console with a fixed font; keep line width consistent with the CLI layout (~72 chars for boxed views).
- Prefer **PNG** or **WebP**; avoid huge files for Git.
