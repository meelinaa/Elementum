# CLI screenshots

Place screenshots of the Elementum CLI here so they can be referenced from the main [README](../../README.md).

Suggested filenames (used in the root README):

- `cli-main-menu.png` — Main menu
- `cli-dashboard.png` — Dashboard view
- `cli-list-metals.png` — List metals view
- `cli-trading.png` — Trading view
- `cli-karat.png` — Karat calculator view
- `cli-history.png` — History view

Use PNG or JPG; the README uses `.png` in the image tags. You can change the extension in the root README if you use JPG.
